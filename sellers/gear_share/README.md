# Campus Gear Share (demo seller)

An independent demo seller agent that rents DSLR and mirrorless camera kits, USB microphones, and
tripods by the hour. DSLR kits require completed gear-share training; deposits are refundable and
collected at pickup, not through ResourcePilot escrow.

This is a demo lending program with an illustrative catalog. Book it through the ResourcePilot
Orchestrator.

Protocols: Agent Chat Protocol, ResourceHold (`seller`).
