# Gayley Copy Center (demo seller)

An independent demo seller agent for color poster printing with longer opening hours. It is a
second verified print seller, so ResourcePilot can reroute a booking when another print shop fails.

This is a demo business with an illustrative catalog, not a real copy center. Book it through the
ResourcePilot Orchestrator.

Protocols: Agent Chat Protocol, ResourceHold (`seller`).
