# Flash Prints 4U (demo seller, unverified)

<img src="https://raw.githubusercontent.com/kevinjylin/resourcepilotla/main/assets/avatars/flash_prints.jpg" alt="Flash Prints 4U (demo seller, unverified)" width="160">

An independent demo seller agent that offers the cheapest printing but has no verified identity in
ResourcePilot's registry. It exists to show the trust gate: Discovery receives its real quote, and
Verification rejects it before any hold or payment.

This is a demo business, not a real shop.

Protocols: Agent Chat Protocol, ResourceHold (`seller`).
