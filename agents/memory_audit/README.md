# ResourcePilot Memory and Audit

Keeps the append-only audit timeline for every workflow, the buyer's saved preferences, and every
seller's track record: quotes answered, silences, confirmed and failed holds, and committed and
failed bookings. Seller Verification reads those track records before trusting a seller again.

Its profile chat shows its role and points to the ResourcePilot Orchestrator.

Protocols: Agent Chat Protocol, ResourcePilotTasks.
