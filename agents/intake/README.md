# ResourcePilot Intake

<img src="https://raw.githubusercontent.com/kevinjylin/resourcepilotla/main/assets/avatars/intake.jpg" alt="ResourcePilot Intake" width="160">

Turns a submitted form into a validated brief for one campus service. A study-room search gets the
day, time of day, length, and group size. A housing lookup gets just the school. The demo project
bundle gets its resources, time window, budget, priority, starting point, and gear training.
ResourcePilot takes requests only from cards and forms, never free text. A school email arrives
already reduced to its domain, and Intake keeps only that. It reports missing details instead of
guessing, so the Orchestrator can show the form again.

Its profile chat shows its role and points to the ResourcePilot Orchestrator.

Protocols: Agent Chat Protocol, ResourcePilotTasks.
