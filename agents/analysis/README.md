# ResourcePilot Logistics Analysis

<img src="https://raw.githubusercontent.com/kevinjylin/resourcepilotla/main/assets/avatars/analysis.jpg" alt="ResourcePilot Logistics Analysis" width="160">

Checks whether each trusted offer can actually work. It drops offers that cannot be ready before
the booking starts, and estimates walking time from the buyer's starting point to each demo shop.
A live study room at the student's own school has no campus coordinates here, so it is left out
of the walking route.

Its profile chat shows its role and points to the ResourcePilot Orchestrator.

Protocols: Agent Chat Protocol, ResourcePilotTasks.
