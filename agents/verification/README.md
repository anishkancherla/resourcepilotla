# ResourcePilot Seller Verification

Decides which quotes ResourcePilot is willing to show a buyer. Each quote must pass identity (the
sender matches the registry and the listing is verified), protocol conformance (version, currency,
hold window, listed categories, and price arithmetic), track record (failure rate and a new-seller
spending cap), and policy (availability and eligibility, such as gear training for DSLR kits).

Its profile chat shows its role and points to the ResourcePilot Orchestrator.

Protocols: Agent Chat Protocol, ResourcePilotTasks.
